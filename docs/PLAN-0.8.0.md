## M3. Новые документы — ядро глубины (~1 день)

Два новых типа, оба появляются постепенно, как остальные правила:

- [ ] **Справка с места работы** — для граждан АССР, с дня 3.
      Поля: завод/институт, должность, дата выдачи, печать.
      Новые нарушения:
      - справка просрочена (старше года);
      - место работы из стоп-листа (закрытые объекты после диверсии на
        реакторе №3 — правило появляется в директиве дня 3).
- [ ] **Транзитная декларация** — для иностранцев с целью «ТРАНЗИТ», с дня 4.
      Поля: груз, маршрут, пункт назначения, печать таможни.
      Новые нарушения:
      - запрещённый груз (компоненты для атомной программы Отеплии);
      - пункт назначения закрыт для транзита.
- [ ] Справочник в книжке: страница «стоп-лист объектов» и «закрытые города».
- [ ] Иконки, лоток, отдача посетителю, всё в RU и EN.

## M4. Визиты комиссара Краснограда — фишка версии (~1 день)

- [ ] Комиссар приходит в очередь как особый визитер:
      - день 3 — после диверсии (сюжетный, обязательно);
      - день 5 — перед Великим Запуском (сюжетный);
      - дополнительно — случайно, если подозрительные флаги
        (взятки, доверие Запада ≥ 3).
- [ ] Пока комиссар «на посту» (3 посетителя после его прохода):
      - **таймер на решение** ~45 секунд на посетителя;
      - истёк — протокол «волокита на посту» (−₳) и едкая реплика;
      - индикатор таймера в хедере, тикает по-армейски.
- [ ] Если флаги подозрительные — короткий допрос инспектора
      (2–3 варианта ответа): влияет на концовку, может спасти
      «подозреваемого» или добить репутацию.
- [ ] Спрайт комиссара: пиксельный, в той же стилистике 48×60,
      шинель, фуражка, папка.
