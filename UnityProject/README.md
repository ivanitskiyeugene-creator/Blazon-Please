# «Гербы, пожалуйста!» — Unity port

Первый игровой Unity-порт браузерного прототипа. Проект рассчитан на **Unity 2022.3.62f3 LTS** и сейчас нацелен на Windows 11. Интерфейс построен на uGUI и сразу использует стандартные события Unity, поэтому кнопки работают как мышью, так и касанием.

## Как открыть

1. Открой Unity Hub.
2. Нажми **Add project from disk**.
3. Выбери папку `UnityProject`.
4. Убедись, что выбрана версия **2022.3.62f3 LTS**.
5. Открой `Assets/Scenes/Main.unity` и нажми Play.

UI и игровой контроллер создаются автоматически при запуске сцены. Вручную добавлять объекты на сцену не нужно.

## Сборка под Windows

В редакторе выбери:

`Blazon Please → Build → Windows x86_64`

Готовая сборка появится в `UnityProject/Builds/Windows/BlazonPlease.exe`.
